# Voxear's prompt icons

The pictures in `Prompts.png` are from **Input Prompts** by **Kenney**, given to the public domain under Creative
Commons Zero (CC0 1.0), so Voxear, and every game made with it, can use and ship them freely.

Nothing is owed. If these icons help your game, you can thank their maker by paying what you like for the pack, or
by donating:

- Input Prompts: <https://kenney-assets.itch.io/input-prompts>
- Kenney's site: <https://kenney.nl/assets/input-prompts>
- Donate: <https://kenney.nl/donate>

`Prompts.png` holds the pack's 64-pixel icons for the controls Voxear binds, and `Prompts.prompticons` names each
control's part of it.
