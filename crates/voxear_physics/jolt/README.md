# Jolt Physics, vendored

Jolt Physics 5.6.0, by Jorrit Rouwe, from <https://github.com/jrouwe/JoltPhysics> at the tag `v5.6.0`: its `Jolt/`
folder only, unchanged, under the MIT licence in `LICENSE`. `build.rs` builds it with Voxear's shim in `../shim/`.

To move to a newer Jolt, replace `Jolt/` with that release's, keep this note's version in step, and run the crate's
tests.
