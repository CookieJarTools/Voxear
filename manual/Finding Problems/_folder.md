When something goes wrong, or the game runs slowly, these tools help you find out why:

- [[The Console]] shows every message your game and the editor write, errors included, with the code that wrote each one.
- [[The Profiler]] shows where the time goes in each frame.
- [[The Frame Debugger]] shows how a frame is drawn, step by step.
- [[The Entities Panel]] shows the engine's own view of what is in the world.
- [[Debugging a Running Game]] covers the tools built into the game itself, for when it runs outside the editor.
