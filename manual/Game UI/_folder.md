Your game's menus and on-screen displays, such as a score or a health bar, and panels in the world, such as a terminal or a sign, are made with **Voxear UI**, the same UI the editor itself is built with. It works much like a web page: one file says what is on screen, a style sheet says how it looks, and your scripts make it work.
