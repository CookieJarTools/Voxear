Everything in a Voxear game is built from the same few pieces:

- An **Obj** is one thing in the world: a crate, a light, the player.
- **Components** give an Obj what it does: a model to draw, a light to shine, a script to run.
- A **scene** is a file of Objs.
- A **level** is a list of scenes that load together. The game loads levels.
- A **prefab** is an Obj saved as a file of its own, to use again and again.

Read [[Objs and Components]] first, then [[Scenes and Levels]] and [[Prefabs]].
