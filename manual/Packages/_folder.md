A package carries scripts, editor tools, assets, pages and samples from one project to another. Use packages to share a camera system between your own games, to add a tool someone else made, or to give your team one copy of the code you all use.

1. [[Adding Packages]], from Git, a folder or a registry
2. [[Making a Package]], with its scripts, assets, pages and samples
3. [[Publishing a Package]], so other people can add it by name

If you know Unity, packages work much as Unity's do: `packages.toml` is Voxear's `manifest.json`, and a Git URL with a tag works as a Unity Git URL does.
