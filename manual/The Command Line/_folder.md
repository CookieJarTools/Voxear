`vox`, the command line that comes with Voxear, does from a terminal what the editor does with a mouse, so scripts, automated tests and AI assistants can work on a game too.

- [[Driving the Editor from a Terminal]] makes changes in an open editor, Obj by Obj and field by field, each one a step you can undo, and connects an AI assistant to it.

Other pages cover the commands for their own work: `vox new` in [[Your First Project]], `vox build` in [[Making a Build]], `vox console` in [[Debugging a Running Game]], and `vox render` in [[Post-Processing]].
