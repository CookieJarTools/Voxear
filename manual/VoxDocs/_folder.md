VoxDocs is where your project's own documentation lives: pages on how your game works, kept beside the game itself. It is the tab next to Scene and Game.

Each page is a plain Markdown file in your project's `Docs` folder. Markdown is ordinary text with a few marks for headings, lists and links, so you can write pages here or in any text editor, and they go into git with the rest of your project.

The tree down the left side holds three kinds of pages:

- **Your project's pages**, at the top.
- **The Voxear Manual**, which you are reading. It comes with the engine, so it always matches the version you have open. You can read it and link to it, but not change it.
- **The Code Reference**: a page for every public type in your scripts and in Voxear, made from the `///` comments in the code.
